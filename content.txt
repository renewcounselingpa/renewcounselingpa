#  This is the ONE file to edit to change the words on the website.
#  See EDITING.md for step-by-step instructions (no GitHub experience needed).
#
#  QUICK RULES
#   - Each line looks like:   name: the text that appears on the website
#     Only change the text AFTER the first colon. Never change the name before it.
#   - A line starting with # is a note to you. It never appears on the website.
#   - Some entries are lists. The name is on its own line, then each item
#     starts with "- ":
#         tags:
#         - First item
#         - Second item
#     To add an item, add another "- " line. To remove one, delete its line.
#   - In a few lists, a "|" separates two parts, like "Title | Description".
#   - Just type & normally (Trauma & PTSD). No special codes are needed.
#
#  SPECIAL MARKS YOU CAN USE INSIDE TEXT
#   **bold text**                  makes text bold
#   *italic text*                  makes text italic
#   [link words](https://...)      makes a link  (use contact.html#contact-form
#                                  to link to the contact form)
#   {phone}  {email}               become clickable phone and email links
#   {years}  {fee_individual}      fill in the matching setting from below, so a
#                                  number only has to be changed in one place
#   [[text]]                       a yellow "still to do" highlight
#
#  After you save, the site updates by itself in a minute or two.
